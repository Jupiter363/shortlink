沿用已确认的「木星中继站」主题，补全 Figma 首轮稿遗留的交互、控件、响应式布局和验收入口。关联 [前端重构 Issue #27](https://github.com/Jupiter363/shortlink/issues/27)。本轮没有调用插件，Figma 云端对象未改变。

## 打开原型

在仓库根目录执行：

```powershell
node doc/design/relay-preview/preview.mjs
```

打开 [本地原型](http://127.0.0.1:5189/#/login)。演示账户为 `Jupiter`，密码为 `12345678`。服务器仅监听 `127.0.0.1`，使用现有 `frontend/console-vue/node_modules` 内的 Vue 与 qrcode；没有新增 npm 安装。

这是一套 Vue 交互设计原型，使用内存数据与演示延迟。刷新会重置业务数据；勾选“记住登录”只持久保存演示 token 和用户名，不保存密码。注册、密码修改、停用等仅在当前页面运行期间有效。5189 原型与 5174 现有前端分别运行。

## 页面与入口

| 页面 | 原型路由 | 主要交互 |
| --- | --- | --- |
| 登录 / 注册 | `#/login`、`#/register` | 校验、密码显隐、记住登录、注册后登录、初始化门、失败恢复与回跳 |
| 短链接工作区 | `#/home/space` | 分组管理及拖动/按钮排序、今日/累计指标、创建、编辑、冲突、二维码、批量任务 |
| 回收站 | `#/home/recycleBin` | 恢复、永久删除、短码确认、并发版本冲突 |
| 访问统计 | `#/home/analytics` | 单链/分组、日期范围、图表/数据表、十类维度、访问记录与快照游标 |
| 投放分析 Agent | `#/home/agent/campaign-analysis` | 独立会话、范围、输入、通用等待、完整回答、证据、完成后执行轨迹 |
| 风险中心 | `#/home/risk-center` | 证据、人工审核、自动限流结果、已有策略停用与原 commandId 核验 |
| 安全风控 Agent | `#/home/agent/security-risk` | 独立会话、风险分析、证据与调试详情 |
| 账户中心 | `#/home/account` | 资料修改、核验当前密码、停用确认、退出 |
| 组件与状态 | `#/design/components` | 表单控件、按钮状态、通用错误与恢复、品牌变体、三角色 × 四表情 |
| 设计验收 | `#/design/coverage` | 九页与 F01–F12 入口索引、响应式规则、实际检查记录 |

统计详情通过列表的“统计”或“分组统计”进入；此处独立路由是原型组织方式，不预先决定正式前端的路由或抽屉承载方案。各页折叠的“本地交互演示工具”可切换异常状态，不调用业务接口。

## 本轮补全

- 响应式导航、分组选择、统计数据表、全部统计维度、记住登录、两个 Agent 调试详情均有可操作入口。关闭抽屉保留来源页面，1280px 侧栏包含回收站。
- 九个业务页面均适配 1440、1280、768、390px。窄屏短链表格变为行摘要，完整字段及操作通过详情抽屉访问。
- 增加 Select、TextArea、DateTime、IconButton 等共享控件；品牌提供彩色、单色、小尺寸版本，机器人区分基础角色、领航员和守护员及四种表情。
- 图标复用官方 Phosphor duotone 路径，统一 24px 视框；复制、下载、二维码等图标各自对应实际动作。原始来源与许可见 `components/primitives.js` 文件头。
- 二维码由本地 qrcode 按所选短链生成，可下载 SVG。同步批次导出真实 OOXML / ZIP 格式 XLSX；异步任务终态导出包含全部行结果的 CSV。
- 批量保留 2–500 行同步、501–50,000 行异步及 8 MiB UTF-8 请求体限制；任务可以关闭后继续，取消保留已完成结果。
- 统计使用演示时间窗 2026-09-08 至 09-14。ISP、新老访客、未知值和历史覆盖范围分别解释；示例数据不用于业务结论或容量评估。
- 两个 Agent 使用独立会话。等待中锁定切换，完成后一次性给出回答及执行轨迹；风险审核、自动限流、停用现有策略保持三条独立交互。

## 验证与范围

实际结果见 [qa-report.json](./qa-report.json)，页面截图见 [screenshots](./screenshots/)。使用隔离的本地 Chromium 经 CDP 检查布局与交互，并检查实际下载文件内容。验收页读取同一份报告。

这些检查属于设计原型验收，不代表后端 UAT、真实登录授权、统计正确性、真实 Agent / LLM 调用或部署验收。没有修改现有生产前端、后端或 Docker 配置，也没有替换 Figma 云端稿。后续实施应复用本原型的布局和组件，同时按接口合同完成业务集成。
