# ShortLink 视觉风格样例

本轮用于选择视觉方向，关联 [前端重构 Issue #27](https://github.com/Jupiter363/shortlink/issues/27)。三个方案共享同一组短链示例数据，尚未确定正式设计方向。

| 方案 | 视觉语言 | 布局差异 | 高清预览 |
| --- | --- | --- | --- |
| A 精密蓝白 | 钴蓝、冷白、细分隔线，强调操作效率 | 应用侧栏 + 分组栏 + 完整表格 | [A.png](A.png) |
| B 明亮几何 | 朱红、明黄、编辑式标题，强调辨识度 | 顶部导航 + 目录式分组 + 开放表格 | [B.png](B.png) |
| C 柔和彩色 | 青绿、薄荷、淡紫，强调上下文 | 图标导航 + 横向分组 + 列表与详情分栏 | [C.png](C.png) |

## 本地查看

在仓库根目录运行（需要现有 `frontend/console-vue/node_modules`）：

```powershell
node doc/design/frontend-style-samples/preview.mjs
```

打开 <http://127.0.0.1:5188>，顶部可切换 A / B / C。预览服务仅绑定本机，复用现有 Vue 和 Element Plus 包，不需要新增依赖。

## 样例范围

- 三张 PNG 按 1440 CSS 像素、2 倍像素密度导出，实际宽度 2880 像素。
- 可演示风格切换、分组空态、排序、单链创建/编辑抽屉、批量输入和 C 方案的行详情选择。
- 未连接业务接口；提交不会写入真实数据。二维码、完整统计、Agent 等后续页面仅标明设计入口，尚未展开。
- 采用 taste-skill 的视觉审查方法；后台控件使用项目已有的官方 Element Plus，功能图标使用仓库已保存的官方 Phosphor 图标。许可见 [ICONS-LICENSE.txt](ICONS-LICENSE.txt)。
- 现有前端、后端、Figma 文件均未修改。
