# 架构图图标来源与许可

架构图中的品牌图形使用官方 SVG；通用功能图形复用 Phosphor Icons。全部图标已内联到架构 SVG，不依赖网络、图标字体或运行时组件。品牌标识与 Phosphor 图标分别遵循其来源规则，不能将两类素材统称为 MIT 授权。

## 通用功能图标

来源为 [Phosphor Icons 官方 Core 仓库](https://github.com/phosphor-icons/core)，固定提交 [`2b75f3ad12b420c9504ef05df8d2564a28f8500e`](https://github.com/phosphor-icons/core/tree/2b75f3ad12b420c9504ef05df8d2564a28f8500e)，使用 MIT 许可。
