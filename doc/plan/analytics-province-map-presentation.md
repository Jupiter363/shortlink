# 省份访问分布图呈现提案

状态：2026-09-15 已实现，关联 Issue #50。标题问号的统计口径提示沿用已有实现。

## 入口与空间

延续仪表盘自身的操作入口和固定卡片布局。在“地域与网络”的“省份”维度提供“地图 / 排名”切换：卡片中的地图只呈现省份轮廓、颜色与简洁图例，避免把所有省名挤在小画面中。卡片内提供“查看大图”，不在顶部导航新增操作。

大图使用 1000px 宽、自适应内容高度的弹窗，地图和排行按 60% / 40% 分配，排行至少 260px。查看详细分布不会推移或扩高现有仪表盘。手机使用全屏弹窗，地图 240px 高，下方为选中省份信息和排行；不依赖悬停。

## 图形与数值

- 适合现有数据的是省级区域填色图，颜色深浅表示访问次数。不是城市散点或真实经纬度热力图。
- 使用单一蓝色的五档深浅，图例明确每档对应的次数范围。变化范围和日期时，图例随实际数据更新。
- 只有接口明确返回的 0 才显示为零值；未返回地区为中性灰并注明“未提供数据”。
- 无法识别省份的数量独立显示，不涂到任何省份，也不与国家未知数混算。
- 悬停或选中显示省名、次数、原始统计占比；占比直接沿用现有 `dimensionView`，不重新归一化为 100%。
- 现有省份分母可能使用 `eligibleCount`，缺失时回退总 PV；未经接口确认不能一概标成“中国访问占比”。
- 数据未匹配底图名称的条目仍保留在排行，明确未匹配，不猜测归属。

## 地图与排行联动

悬停地图时高亮对应排行；悬停排行时高亮对应区域。点击或键盘选择固定当前省份，显示准确数值，点击空白或清除选择取消。只改变展示中的选中项，不改变当前分组、日期或访问记录查询范围。

排行按访问次数排序，所有返回项目可滚动查看。手机点击省份后使用固定信息条，避免提示浮层挡住小地图。地图保持固定视图，不提供拖拽缩放；清除选择可恢复未选中状态。

## 实现与边界

底图使用固定版本 Apache ECharts 4.9.0 的省级边界与南海附图，确定性解码投影为本地 SVG 路径；保留上游所有环及顶点，随构建分发来源、Apache LICENSE 和 NOTICE。它是历史概览资源，不是实时测绘边界服务，来源与复现脚本见 `frontend/console-vue/src/relay/assets/china-provinces.SOURCE.md`。

省级名称/编码通过明确别名表映射。多个原始条目映射到同一省份时不擅自相加或选取，相关省份保持未提供数据，并将所有原条目标为名称冲突。未识别及未匹配条目保留在排行下方。

地图资源按需加载，失败时可以重试，排名保持可用。SVG 支持一个 Tab 入口、方向键、Home/End 和 Enter/Space 选择；Escape 关闭原生弹窗并恢复焦点。现有数据只有省级分类计数，不支持省份 UV/UIP、城市热点、地理坐标或省份增长率，不能从现有 PV 推造。
