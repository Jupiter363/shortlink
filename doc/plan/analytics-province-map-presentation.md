# 省份访问分布图呈现提案

状态：设计提案，尚未接入地图。当前另行实现标题问号的统计口径提示。

## 入口与空间

延续仪表盘自身的操作入口和固定卡片布局。在“地域与网络”的“省份”维度提供“地图 / 排名”切换：卡片中的地图只呈现省份轮廓、颜色与简洁图例，避免把所有省名挤在小画面中。卡片内提供“查看大图”，不在顶部导航新增操作。

大图使用约 960×620px 的弹窗，地图和排行按 60% / 40% 分配，排行至少 240px。查看详细分布不会推移或扩高现有仪表盘。手机使用全屏弹窗，地图约 220–260px 高，下方为排行和选中省份信息；不依赖悬停。

## 图形与数值

- 适合现有数据的是省级区域填色图，颜色深浅表示访问次数。不是城市散点或真实经纬度热力图。
- 使用单一蓝色的五档深浅，图例明确每档对应的次数范围。变化范围和日期时，图例随实际数据更新。
- 只有接口明确返回的 0 才显示为零值；未返回地区为中性灰并注明“未提供数据”。
- 无法识别省份的数量独立显示，不涂到任何省份，也不与国家未知数混算。
- 悬停或选中显示省名、次数、原始统计占比；占比直接沿用现有 `dimensionView`，不重新归一化为 100%。
- 现有省份分母可能使用 `eligibleCount`，缺失时回退总 PV；未经接口确认不能一概标成“中国访问占比”。
- 数据未匹配底图名称的条目仍保留在排行，明确未匹配，不猜测归属。

## 地图与排行联动

悬停地图时高亮对应排行；悬停排行时高亮对应区域。点击或键盘选择固定当前省份，显示准确数值，点击空白或清除选择取消。只改变展示中的选中项，不改变当前分组、日期或访问记录查询范围。

排行按访问次数排序，所有返回项目可滚动查看。手机点击省份后使用固定信息条，避免提示浮层挡住小地图。地图预览不提供拖拽缩放，完整弹窗按需提供恢复视图。

## 实施前需完成的展示准备

使用可核验来源、授权与完整边界的省级地图资源，并保留要求的来源标识；建立省级名称/编码与底图之间的明确映射。现有数据只有省级分类计数，不支持省份 UV/UIP、城市热点、地理坐标或省份增长率，不能从现有 PV 推造。
