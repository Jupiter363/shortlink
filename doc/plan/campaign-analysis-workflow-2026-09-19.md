# 投放分析工具与上下文优化

关联 Issue #59，按用户确认顺序实施。

1. 多期间、多对象与上下文：每个对象和期间形成独立查询，明确拒绝歧义；保存已解析范围与服务返回的续页引用。会话按当前用户名、tenant、authVersion 隔离，每次查询重新授权。趋势不额外读取访问明细。异步状态只检查一次，成功后读取真实结果页。
2. 对比与排名：以统计快照为事实，程序计算差值、变化率、贡献和排名，保留窗口、近似口径与质量。日期不等长、未结束期间、零基期和 PARTIAL 不能被包装为确定的效果提升。排名覆盖完整授权范围，跨日 UV 重新按整窗去重。
3. 多维下钻：在去重后的有效 CLICK 事实上，以白名单维度和过滤条件计算联合分布；支持地域、设备、时间和来源域，保留 UNKNOWN 与非适用分类。过滤范围绑定快照，续页不能换条件。UTM、费用、转化与 ROI 不在现有事实中，不生成此类指标。

验收分层：规划器与真实 Graph 多轮测试 → 聚合与工具合同测试 → Admin 授权转发。按用户最新要求，OOM 修复阶段只执行后端测试，不启动 Docker 或重做浏览器验收；此前前端及隔离 ClickHouse 测试与最终后端结果在验收报告中分开记录。

保留已有业务数据、D 盘 Docker 数据位置和较宽松的有限内存配额，不运行压力测试。原有未提交的交接文档与索引独立保留。
