# 双 Agent 工作台布局优化

关联 Issue #55。保留投放分析与安全风控的角色形象、配色、分析方向卡片，改善提问和结果核验时的空间利用。

## 现状与方向

桌面初始页面左侧提问卡约 400px 高，右侧三个分析方向约 390px 高，两列下方留白较多。输入区域偏短；会话说明内联展开挤压内容；历史回答埋在结果正文里。现有分析方向和入口视觉已获认可，继续使用 Vue/R 组件及木星主题。参考 taste-skill 的先审视再改造原则，不替换为营销页模板或新组件系统。

- 顶部导航只保留标题。正文会话工具栏呈现当前状态、所选范围、新会话、历史分析与使用说明。
- 提问区适当加高输入框，加入清空问题、复用上次成功提问、Ctrl/⌘ + Enter 提交，以及本会话完整回答数量。
- 分析方向卡片保留。访问统计与风险中心统一使用左侧导航，不在 Agent 初始页面重复设置数据核验入口。
- 完整回答增加复制与 Markdown 报告导出；历史分析在抽屉中选择和只读查看；使用说明和复制失败的手动文本在弹窗中展示。
- 工作区采用单一正文滚动，手机保留提问/结果切换。窄屏按钮换行，长问题与报告可折行，不新增卡片内滚动框。

## 行为与数据边界

清空只影响草稿；复用恢复最近一次成功提交的问题及仍有效的分组。历史条目保留提交时的范围，不随当前选择改变。两个 Agent 的会话继续独立，刷新、退出登录或新会话时不保留历史，页面说明明确标注。

停止等待只结束前端请求等待，不宣称服务端任务已取消。继续使用原有全局忙碌锁、请求版本校验及迟到响应保护，风险分析可能触发服务端自动限流的说明保留。

历史与导出沿用已有脱敏规则。报告仅包含完整响应中可见的回答、证据、提示、数据来源、工具轨迹与待处理事项；缺失字段不补成功结论，保留证据标识，不导出会话运行对象。后续请求失败时，保留结果标为“上一次完整结果”。

## 验收

检查两个 Agent 在桌面和手机上的布局、示例填入、清空、会话隔离、只读历史与说明弹窗；用纯函数测试验证历史快照、范围留存、导出字段和脱敏。执行前端 lint、test、build。本轮不发送模型分析请求、不触发风控策略变更。
