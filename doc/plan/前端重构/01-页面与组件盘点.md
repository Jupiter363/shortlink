# ShortLink 前端重构：页面与组件盘点

> 状态：Figma 设计输入基线
> 对应 Issue：[#27](https://github.com/Jupiter363/shortlink/issues/27)
> 工作分支：`jupiter/refactor-frontend`

## 1. 盘点结论

本轮从零重做视觉与前端结构，但继续复用新版后端的业务、路由兼容入口、身份边界和数据语义。Figma 首轮需要覆盖：

- **9 个一级页面模板**；
- **12 条可走通的关键业务流程**；
- **8 组组件族**及其交互状态；
- 桌面端主稿、窄屏适配规则，以及 loading、empty、error、permission、partial 等非理想状态。

`frontend/console-vue` 是迁移期间的业务参考实现，不作为新视觉参考。以下两套后端静态页不再生成新版本，待新版前端完成迁移后删除：

- `services/admin/src/main/resources/static/agent-admin/`
- `services/agent-service/src/main/resources/static/agent-console/`

APISIX、Kafka、Redis、MySQL、ClickHouse、Flink、Leaf 等属于系统架构，不在本轮生成独立运维页面。若以后需要运维控制台，应另立需求和权限模型。

## 2. 一级页面地图

| 编号 | 页面模板 | 路由或入口 | 必须呈现的核心内容 | 设计说明 |
| --- | --- | --- | --- | --- |
| P01 | 登录 | `/login` | 账号密码、记住登录、字段校验、提交状态、回跳提示 | 登录成功支持 `redirect` 回跳；记住登录只持久保存 token/username，不保存密码 |
| P02 | 注册 | 建议新增 `/register`，并兼容 `/login` 内切换 | username、password、realName、phone、mail、用户名占用检查 | 注册响应不含 token；注册成功后先登录，取得登录态后再查询初始化 |
| P03 | 短链接工作区 | `/home/space` | 分组导航、短链列表、受支持排序、核心指标、创建、批量创建与任务进度入口 | 产品主页面；高密度数据工作区，不做营销型卡片墙 |
| P04 | 回收站 | `/home/recycleBin` | 已回收短链、恢复、永久删除、版本冲突 | 当前路由组件是空壳、实际能力嵌在工作区；新版应补成同一套信息架构下的真实页面 |
| P05 | 统计详情工作区 | 从短链或分组进入 | PV/UV/UIP、趋势、地域、时段、终端、ISP、新老访客、访问记录 | 交互查询最多 7 天、最多 500 条短链；当前为弹窗，Figma 同时给出桌面抽屉/全屏承载方式 |
| P06 | 投放分析 Agent | `/home/agent/campaign-analysis` | 分析范围、任务输入、RUNNING、结论、证据、完成后的 Tool/Graph 轨迹 | 偏流量与投放洞察；不是普通聊天页 |
| P07 | 风险中心 | 建议新增 `/home/risk-center` | 分组风险概览、高风险短链、风险事件、短链当前策略、人工审核、策略停用结果 | 固定的运营与审计界面；不能由对话式 Agent 代替 |
| P08 | 安全风控 Agent | `/home/agent/security-risk` | 风险分析请求、回答、证据、完成后的 Tool/Graph 轨迹、自动限流结果 | 与投放 Agent 共享工作台骨架，保持独立会话和风险语义 |
| P09 | 账户中心 | `/home/account` | 账号资料、编辑资料、修改密码、自助停用账户、保存反馈 | username 只读；改密和停用均要求当前密码，停用后不能自助恢复 |

登录后的页面共用全局应用壳：品牌入口、主导航、当前页面上下文、账号菜单、退出和全局反馈层。主导航承载短链接、风险中心、投放分析 Agent、安全风控 Agent；回收站属于短链接域，账户中心位于用户菜单。`/`、`/home`、`/home/agent` 仅作为兼容重定向入口，不单独生成页面；另生成 404/返回工作区支持帧。

## 3. 十二条关键业务流程

| 编号 | 流程 | 必须生成的关键帧 |
| --- | --- | --- |
| F01 | 登录、注册与受保护页面回跳 | 默认、记住登录、校验失败、提交中、账号错误/已存在、注册后登录、初始化门、登录成功回跳、会话失效 |
| F02 | 分组管理 | 新建、重命名、拖拽排序、删除确认、初始化 groupId 的 UI 保护、配额/占用失败 |
| F03 | 创建单条短链 | 填写 URL、自动获取标题、手工描述、分组、永久/自定义有效期、成功结果 |
| F04 | 批量创建 | 2–50,000 行与 8 MiB 请求体双重校验、链接与描述数量校验、同步成功、异步接单、jobId 进度、取消、部分失败/结果导出 |
| F05 | 编辑短链 | 编辑信息、提交中、成功、`expectedVersion` 冲突、刷新后重试 |
| F06 | 短链使用 | 复制短链、二维码预览、二维码下载、过期/失效提示 |
| F07 | 统计查询与下钻 | 单链/分组范围、日期范围、指标趋势、维度切换、图表/表格切换、数据口径 |
| F08 | 访问记录浏览 | 单链/分组与日期范围、脱敏记录、快照游标前后翻页、游标失效、部分数据 |
| F09 | 回收站生命周期 | 移入回收站、恢复、永久删除、不可逆确认、并发版本冲突 |
| F10 | 投放分析 Agent | 新会话、选择分析范围、快捷指令、通用 RUNNING、完整结果、完成后的执行轨迹、失败重试 |
| F11 | 风险中心与安全风控 Agent | 分组风险概览、短链风险详情、事件审核、当前策略查看/停用、Agent 分析、自动限流结果、命令结果待核实 |
| F12 | 账户与会话 | 查看资料、编辑保存、修改密码、退出、账号初始化恢复、401 统一回登录并保留回跳地址 |

Figma 原型至少要完整走通 F01、F03、F07、F10、F11；其余流程需有主帧和异常状态帧。

## 4. 组件清单

### 4.1 Foundations 与应用壳

- 色彩、间距、尺寸、圆角、层级、断点和动效参数使用 Variables；字体使用 Text Styles，阴影使用 Effect Styles；
- `JUPITER RELAY / 木星中继站` 主题基础：相扣轨道环品牌标记、明亮漫画线条、面板边界与操作控件规范；
- 原创潮玩机器人角色板：投放分析 Agent 的“领航员”与安全风控 Agent 的“守护员”共享造型语言、保持可辨认的角色特征；角色名仅作辅助身份，保留正式中文导航与页面名称；
- `AppShell`、展开/收起侧栏、主导航项、顶栏、页面标题、面包屑；
- 当前范围栏（短链/分组/日期）、用户菜单、帮助菜单；
- 内容分栏、上下文详情区、可收起辅助面板；
- 桌面 1440px 主栅格，以及 1280px、768px、390px 的布局规则。

### 4.2 基础输入与操作

- 主按钮、次按钮、文字按钮、危险按钮、图标按钮；
- 文本框、密码框、文本域、选择器、复选框；
- 日期范围、日期时间、分段控制、受支持的排序器；
- 表单字段、必填提示、字数/行数计数、行级错误；
- default、hover、focus、active、disabled、loading 状态。

### 4.3 全局反馈与浮层

- Toast、Inline Alert、Tooltip、Popover；
- Dialog、Drawer、危险操作确认、离开未保存确认；
- Skeleton、局部刷新、空状态、搜索无结果、错误状态、权限状态；
- 异步任务状态、进度、重试、取消、成功结果；
- 数据新鲜度、完整度、历史覆盖范围和 unknown 提示。

### 4.4 分组与短链接管理

- `GroupRail`、分组项、数量、选中态、排序手柄、分组菜单；
- `LinkTable`、链接身份单元格、favicon、原始 URL、短链、时间和状态单元格；列表查询只使用 `gid/current/size/orderTag`，不设计无接口支撑的关键词或维度筛选；
- PV/UV/UIP 指标单元格、今日/累计切换、排序表头；
- 行操作、分页器；不设计无接口支撑的批量编辑、批量移动或批量回收操作；
- 单链创建表单、批量行编辑器、编辑表单；
- 有效期选择器、标题抓取状态、二维码预览、复制反馈；
- 批量任务抽屉、任务进度、取消、结果游标、失败行详情、版本冲突提示；同步创建按 `requestId` 导出 XLSX，异步 job 仅在终态按 `jobId` 导出 CSV；
- 2–500 行走同步结果，501–50,000 行走异步 job；使用可承载大文本的行编辑/粘贴体验，不沿用旧前端 100 行上限；
- 行数和序列化请求体必须同时校验，超过 8 MiB 时阻止提交并说明当前没有浏览器文件上传替代流程；
- 回收站行操作与永久删除确认。

### 4.5 统计与数据可视化

- 分析范围摘要、日期范围、统计更新时间、指标口径入口；
- DateRange 最多 7 天；分组授权范围超过 500 条短链时显示 TOO_LARGE 并引导缩小范围，不生成浏览器历史统计 job 入口；
- PV/UV/UIP 指标带、当前时间窗趋势图、图表/表格切换；当前接口没有正式对比时间窗，不生成同比/环比；
- 国家/省份地域图、维度排行、24 小时分布、一周分布；
- OS、浏览器、设备、运营商/ISP、新老访客组件；
- 高频 IP 表、脱敏访问记录表、快照游标分页；
- `CompletenessBanner`、unknown 独立分类、历史覆盖不足、无法定位地域等状态。

### 4.6 双 Agent 共用组件

- Agent 身份/健康状态、独立会话头、新会话操作；健康只表示 Agent HTTP 入口可达，不代表 Graph、Analytics、Tool 或 LLM 分别就绪；
- 分析范围摘要/选择、Prompt Composer、快捷指令；范围控件只将选择结果转换为现有 `message` 文本，权限范围仍由服务端登录主体决定；
- 请求中的切换锁定、通用 RUNNING、完成后一次性回答；当前同步 POST 不生成虚假的流式文字或实时节点进度；
- 洞察卡、警告栈、指标证据、图表证据；
- 数据来源、统计口径、更新时间；
- 完成后 Tool 调用时间线、Graph 节点、Trace 摘要；
- 脱敏访问记录、调试数据折叠区、失败重试和部分结果提示。

### 4.7 风险中心与安全风控专用组件

- 分组风险概览、风险计数、风险趋势、高风险短链列表；
- 短链风险详情、窗口指标、reason codes、近期风险事件；
- 风险事件列表、事件证据、建议动作、提交审核；当前没有审核历史/待办列表接口，不虚构独立审核队列；
- 当前策略列表、策略覆盖、策略详情、停用策略确认、Command 结果轮询；
- 风险等级、风险信号、证据链；
- 策略建议、影响范围、动作预览；
- 审核结论状态机：WATCH、UNWATCH、FALSE_POSITIVE、CONFIRM_RISK、IGNORE；它只记录人工判断，不自动执行或撤销策略；
- Agent 自动限流状态机：展示 Agent 可能提交的 `LIMIT_RATE` 结果及证据，不能泛化成任意动作批准器；
- 人工停用已有策略状态机：二次确认、稳定 commandId、已提交、已执行、状态待核实、执行失败；
- 不生成通用的 DISABLE_SHORT_LINK、BLOCK_IP 或 LIMIT_TIME_WINDOW “批准后执行”按钮。

### 4.8 认证与账户组件

- 登录/注册认证壳、密码显隐、记住登录、8–15 位要求提示；记住登录不保存明文密码，当前没有验证码 challenge API；
- 账号冲突、异地登录/重复登录、会话失效提示；
- 默认分组初始化状态、下次重试时间、失败原因和手动重试；
- 资料描述列表、资料编辑表单、username 只读字段；
- 当前密码确认、修改密码、自助停用账户和不可恢复提示；
- 保存中、保存成功、校验失败、服务失败和退出确认。

## 5. 必须单独设计的状态矩阵

| 领域 | 状态 |
| --- | --- |
| 全局 | 首屏加载、局部刷新、离线/网络失败、401、403、429、504/超时、可重试、成功反馈 |
| 分组/短链 | 空分组、正常、即将到期、已失效、标题抓取中/失败、提交中、版本冲突 |
| 批量创建 | 行数不匹配、超过 8 MiB、同步完成、VALIDATING、READY、RUNNING、SUCCEEDED、PARTIAL_SUCCESS、FAILED、CANCELLED、非终态不可导出、导出 429 繁忙 |
| 回收站 | 空态、移入中、恢复中、永久删除中、版本冲突、不可逆结果 |
| 统计 | 加载、真正无数据、PARTIAL、unknown、历史覆盖不足、快照/游标失效、翻页中、超过 7 天、范围超过 500 条/TOO_LARGE |
| Agent | 健康检查中、HTTP 入口可达、入口不可达、READY、RUNNING、成功、业务警告、失败、迟到响应丢弃；执行轨迹仅在完成后展示 |
| 风险中心/动作 | 风险数据加载、无事件、TOP_CARDS_ONLY、UNKNOWN；审核显示提交中/已记录/失败，自动限流显示未触发/已激活/失败/传播未知，策略停用显示待人工确认/已提交/已执行/状态待核实/失败 |
| 账户 | 未认证、字段校验、登录/注册中、默认分组初始化 PENDING/FAILED/READY、保存中、成功、业务失败、服务失败、停用后退出 |

状态不能只依赖颜色表达。`unknown` 不能画成 0 或并入真实分类；统计数据尚未完整时必须直接显示数据完整度。

## 6. Figma 不得改变的业务合同

1. 浏览器只通过同源 `/api` 访问系统，不展示或直接调用 Admin、Command、Agent 等内部地址。
2. Agent 类型值固定为 `campaign-analysis` 和 `security-risk`；对话请求只发送 `sessionId`、`agentType`、`message`。
3. 用户、审核人和内部服务身份由后端当前登录主体派生，界面不能提供伪造用户、审核人、租户或内部 Token 的入口。
4. 两个 Agent 使用独立会话；请求中锁定会话与 Agent，切换路由清理旧结果，迟到响应不能串线。
5. 创建短链时 `domain` 默认留空，由 Command 的受控默认域名决定；界面不增加任意填写域名的能力。
6. PV 是访问次数，UV 是访问人数，UIP 是独立 IP 数，三者不可互换。
7. 新老访客按所选短链或分组的历史首次观测判定，并披露可用历史范围。
8. “网络”维度表示 IP 离线解析得到的运营商/ISP，不能声称识别 Wi-Fi、4G、5G。
9. 统计走异步链路；`completeness != COMPLETE` 时提示当前结果不完整，未知维度单列。
10. IP 和访客标识保持脱敏；访问记录使用快照/游标语义，不能伪装成稳定页码。
11. 批量创建既可能同步完成，也可能异步返回 `jobId`；界面必须覆盖任务状态和失败行。2–500 行为同步批次，501–50,000 行为异步 inline job，链接与描述逐行对应。
12. 编辑、移入回收站、恢复和永久删除均携带列表返回的 `routeVersion` 作为 `expectedVersion`；冲突后重新读取资源，不静默覆盖。
13. 初始化状态返回的 `groupId` 可作为默认分组的 UI 保护依据，但当前 Group 后端没有不可变 `isDefault` 标识，不能把它描述成后端强不变量。
14. 风险人工审核只记录 WATCH、UNWATCH、FALSE_POSITIVE、CONFIRM_RISK、IGNORE 等审核结论，不等同于策略已执行或已撤销。
15. Agent 自动限流、风险人工审核、人工停用已有策略是三条独立链路，界面不能把它们合并成一个通用“批准执行”流程。
16. 策略停用必须展示稳定的 commandId 对应结果；超时或上游 5xx 时显示“状态待核实”，不能宣称成功。
17. 每个用户最多 20 个分组，一次排序最多提交 20 个；分组包含短链或活动 job 时，删除失败要保留上下文并解释原因。
18. Agent 消息最多 2000 字；请求期间禁止切换 Agent 或新建会话，两个 Agent 的 session 独立，切换路由清除旧结果。
19. 风险总览返回 `currentPolicyCoverage=TOP_CARDS_ONLY` 时只代表头部风险卡片有策略详情；`disabledCount` 缺失时不显示或推算全组停用数量。
20. 批量 inline 创建同时受 2–50,000 行和 8 MiB 请求体限制；超过任一限制都不能提交，当前也没有浏览器对象上传合同。
21. 交互统计查询最多 7 天、授权范围最多 500 条短链；超过时显示 TOO_LARGE，不能伪造浏览器历史统计 job 入口。
22. 注册接口返回空结果；注册成功后必须先登录取得 token，才能访问账户初始化状态与重试接口。

| 回收、恢复、永久删除 | P04、F09 | 纳入 |
| 批量创建、任务状态、结果游标、取消、导出 | P03 的批量任务抽屉、F04 | 纳入；后端没有任务列表接口，不能虚构全量“任务中心” |
| 单链/分组统计和访问记录 | P05、F07、F08 | 纳入 |
| 投放分析 Agent | P06、F10 | 纳入 |
| 风险分组概览、短链详情、事件、审核、策略停用、命令结果 | P07、F11 | 纳入独立风险中心 |
| 安全风控 Agent | P08、F11 | 纳入；与风险中心互相导航，但不替代固定运营界面 |

`POST /admin/v1/batches/imports` 当前只接收已存在对象的 bucket、key、version、sha256 和 bytes，仓库内没有供浏览器使用的安全上传/预签名合同。因此本轮不生成“本地文件直接上传到对象存储”的可执行流程；等上传合同补齐后再增加导入向导。现阶段只生成已由短链创建流程返回的批量任务详情、取消和结果导出。

### 7.1 明确不生成的页面与操作

- 独立批量任务中心、任务历史搜索、失败行重跑和 job 重试；
- 独立导出中心，以及让用户任意选择 CSV/XLSX 的通用导出器；
- 对象存储文件上传页，直至预签名上传和对象归属合同补齐；
- 全局策略 CRUD、重新启用策略或独立策略管理中心；
- 独立人工审核队列/审核历史页，以及任意 commandId/linkId 调试台；
- 用户列表、角色/RBAC、管理员代操作、邀请成员；
- 找回密码、邮箱验证、MFA、独立账户初始化管理中心；
- 浏览器历史统计 job 页面；
- APISIX、Kafka、Redis、MySQL、ClickHouse、Flink、Leaf 运维控制台。

B0–B6 是同一次主生成中的内部执行顺序，不代表必须分别调用七次。各阶段复用前一阶段建立的 Figma Variables、Text Styles、Effect Styles 和组件，不让 AI 重新发明色彩、按钮、表格或导航。按[低调用生成提示词](02-Figma-AI低调用生成提示词.md)执行“主生成 → 集中审计补全”；确实受工具能力限制的缺项需标记后集中修复。

## 9. 设计边界与验收

- 设计主题为 `JUPITER RELAY / 木星中继站：原创太空漫画 × 潮玩机器人 × 精致数字工作台`，使用明亮漫画线条、清晰轮廓和克制的实体感，让品牌标记、应用壳、表单与数据区形成统一主题；
- 主题不能只依赖角色插画或给普通后台换色；隐藏机器人插画后，相扣轨道环、导航选中态、按钮与面板边界仍应具有一致辨识度；
- 原创机器人用于品牌、欢迎、空态和两个 Agent 的辅助身份，保持造型、轮廓、比例与表情规范一致，不遮挡正文、表格、图表或证据；“领航员”“守护员”不替代投放分析 Agent、安全风控 Agent 等正式功能名称；
- 使用统一交互主色；品牌装饰色可丰富角色与非状态图形，但与成功、警告、风险和信息等状态色分别定义，不用机器人颜色或表情推断业务状态；
- 功能图标统一使用 Phosphor，保持尺寸与视觉重量一致；原创机器人、轨道环和主题插画单独建立资产规范，不用 Emoji 或角色插画替代功能图标；
- 表格、表单与统计保留清楚的信息层级、可读字体和数据密度，不将数据单元格漫画化，不使用满屏暗色霓虹、全局玻璃拟态、AI 紫色网格、渐变文字或重复等宽卡片墙；
- Agent 是可审计的任务工作台，必须展示范围、请求状态、证据和受控动作；当前同步 POST 期间仅使用通用 RUNNING 提示，角色动效不伪造流式回答、实时 Tool/Graph 进度或依赖服务就绪状态，执行轨迹仅在响应完成后展示；
- 装饰动效不干扰连续阅读与操作，支持减少动态效果；业务状态变化仍以真实响应、文字与图形标识表达；
- 全部组件使用 Auto Layout；色彩、间距、尺寸与圆角绑定 Variables，字体绑定 Text Styles，阴影绑定 Effect Styles；
- 所有简体中文字符必须可读、无乱码、无截断、无文字溢出；按钮文字不换成两行；
- 主图标信息块中，图标与容器顶部至少保留 16px，图标与标题保持 10–12px；该规则不套用于按钮、导航或表格内联图标。正文行高至少 1.5；
- 正文、按钮和状态达到 WCAG AA；焦点可见，状态同时使用文字或图形标识；
- 表格窄屏按优先级隐藏列，并提供行详情入口，不能压缩为不可读内容；
- 任何图表都包含标题、图例、范围、口径、更新时间和空数据状态；
- 官方品牌图标只使用官方资产；缺少资产时保留 Asset Slot，不伪造标志。

主生成与集中审计提示词已保存在[02-Figma-AI低调用生成提示词.md](02-Figma-AI低调用生成提示词.md)。按 B0–B6 顺序在共享设计系统上尽可能一次完成页面与组件，随后集中核对覆盖矩阵并补齐缺项，不为每个页面重复创建组件或单独发起生成调用。
