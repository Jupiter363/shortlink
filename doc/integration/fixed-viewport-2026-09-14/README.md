# 管理台布局与首屏验收

关联 [Issue #40](https://github.com/Jupiter363/shortlink/issues/40)。实施与验收时间：2026-09-14 至 2026-09-15；入口为本地 Docker 前端 `http://127.0.0.1:5174`，使用真实后端与原有 Jupiter 测试账户。

## 设计依据

本轮目标是合理分配卡片大小，让核心数据和操作优先在首屏呈现。保留木星主题、蓝色主操作、黄色导航选中态、现有中文字体、图标和圆角。采用 design-taste-frontend 的保留式改版、信息层级与密度原则（6 / 2 / 6），沿用现有 Vue 和 R 组件体系。

固定视口用于稳定操作区。桌面充分利用标题下的工作区，内容在卡片内部合理分布；手机与矮屏优先紧凑排版。并排卡片、分区切换和按需展开减少内容堆叠；长结果、长列表、编辑表单及极窄短视口保留内部滚动兜底。登录与注册仍允许正常文档滚动。

## 逐页调整

| 页面 | 原问题 | 最终行为 |
| --- | --- | --- |
| 全局 | 重复导航占高，压缩后菜单与内容挤在顶部，品牌周围留白过大 | 左侧主菜单居中；桌面木星品牌区放大，中英文名称与简短文案组合；页面唯一标题和主操作通过共享 PageHeading 移入顶部导航，正文释放高度；顶栏保留木星、机器人与星点装饰及侧栏收起入口，窄屏与矮屏精简装饰；标题无独立填充背景 |
| 短链接 | 控制项多层堆叠，手机卡片过高；内容与分页分离，外部留白过多 | 桌面分组与短链面板撑满工作区，工具条/表格/分页统一为操作面板；记录按稳定行高从上往下排列，不随剩余高度拉大，分组名靠上；手机保留紧凑卡片，细节与次要操作按需查看 |
| 回收站 | 空态与列表依赖文档高度 | 共用自适应工作区，保留恢复、详情及永久删除确认入口 |
| 访问统计 | 筛选、指标、趋势、全部维度纵向堆叠 | 筛选默认收起；概览与维度切换；核心指标与趋势同屏；质量警告始终可见；图表按实际容器大小绘制，稀疏日期标签但不删除数据 |
| 风险中心 | 所有概览、档案、事件、命令卡片连成一长页 | 分为概览、短链档案、风险事件、策略回执；桌面指标与趋势并排，手机按比例压缩卡片 |
| 投放分析 / 安全风控 Agent | 角色介绍与辅助说明挤压输入框，答案、证据和轨迹堆叠 | 提问和结果卡片在中区合理并排，空结果提供可填写的示例任务；回答、证据、执行轨迹分开查看；手机切换提问和结果，返回会话恢复已有回答；安全自动限流提醒仍在提交前可见 |
| 账户中心 | 大型身份卡与资料区重复留白 | 横向身份摘要；基本资料与安全入口并排，安全操作按需展开；保留编辑与停用确认流程 |
| 创建 / 编辑弹窗 | 说明卡占高，分组和有效期分行 | 合理并排字段、精简说明；保持字段绑定、标题抓取、自定义到期时间和提交逻辑 |

## 实际验收

使用原内置浏览器的真实页面，未使用静态仿真页面、替换接口响应或注入假数据。

- 七个操作路由在 1024×768、390×844、320×568 检查文档宽高及可见内容；补充 1024×600、1440×900 和默认 1226×986 的主要页面检查。文档根节点保持视口大小，极窄短视口的长内容在操作区内可达。
- 1024×768 下统计概览、风险概览、两个 Agent 的提问表单、账户默认内容无需内部纵向滚动。1024×600 下也可直接看到两个 Agent 的提交按钮。
- 390×844 下统计概览含指标、趋势和日期完整可见；风险概览也保持首屏展示。最终几何读数见 JSON，不用调整过程中的尺寸代替最终值。
- 1440×900 下标题进入顶部导航后，短链工作区约为 759px 高。两条和四条记录均保持约 114px 的稳定行高，不随记录数拉伸；分组列表从上往下排列。
- 默认创建弹窗内容高度从约 755px 减至约 496px，字段与提交按钮在 1024×600 中同屏；自定义有效期等展开内容仍允许内部滚动。
- 实测显示设置弹窗的累计/今日切换、关闭与焦点恢复；统计“概览 / 访问维度”的左右方向键、Home 键与选中面板关联；访问记录抽屉读取真实记录。
- 实测风险中心四个视图均能切换并展示相应的真实档案、事件或空回执状态，未提交审核或策略命令。
- 投放分析实际完成只读请求，返回回答、三项已完成工具记录及六个 Graph 节点。验证回答/证据/轨迹切换、展开轨迹后的内部滚动、提交后焦点移至结果区，以及手机离开再返回后的会话恢复。
- 账户编辑展开后可在内部滚动到底部，保存与取消按钮可达，文档滚动位置保持 0；本轮取消编辑，未修改账户资料或密码。
- 顶部标题迁移后逐页验证只有一个 h1 且位于顶部导航；原创建、访问记录和新会话操作保持有效。侧栏收起后缩短窗口，自动恢复当前尺寸下可用的布局；装饰不接收指针和键盘焦点。
- Agent 示例任务点击后只填入问题、聚焦输入框；真实只读请求返回三项已完成工具记录。安全页不自动发起请求。
- 完整前端测试 73 项通过，lint、Vite 生产构建及 diff 检查通过。未执行压测，也未新增或重启中间件。

[几何读数](layout-observations.json) 保留最终验收阶段的观测；长回答并不保证无需滚动。

## 边界

本轮是布局与交互回归，未重复执行短链创建/回收/恢复/永久删除或安全策略的写入验收。安全 Agent 验证了页面与入口状态，未再发起自动风控业务请求。真实统计仍披露 PARTIAL、未知地域和运营商等既有数据缺口；布局优化不代表这些数据已经补齐。320×568、长回答、完整证据及展开编辑表单允许滚动，不通过裁剪内容或缩小到不可读字号强行塞进一屏。
