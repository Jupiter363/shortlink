# 风险中心只读 UAT · 2026-09-14

本轮在本地 Docker 后端与真实新前端 `http://127.0.0.1:5174` 上完成，使用隔离 Chromium CDP 会话。登录后只读取风险信息，未调用 Agent chat、人工审核或策略停用接口。

## 验证结果

- 29 项浏览器检查通过，其中 28 项使用真实后端，1 项为明确标记的 UNKNOWN 策略响应故障注入。
- 默认分组与“UAT统计维度样本”均能切换并读取真实概览、短链风险档案及风险事件。每组返回 2 个档案，事件分别为 4 条与 2 条。
- 风险详情使用选中档案的 gid、domain、shortUri；当前策略另以 linkId 读取。首条档案 `linkId=20002` 返回 `KNOWN_ALLOWED`、`revision=0`、无策略记录，页面没有提供停用动作。
- 风险事件证据、指标/数据完整度、历史快照、最近事件证据能够展开。原始 IP、身份哈希和租户字段均按展示口径脱敏；历史快照明确不代表当前策略。
- 1280、768、390 三个视口下，页面、抽屉及展开后的证据都没有横向溢出。每个宽度均验证了初始焦点进入抽屉、Esc 关闭后恢复到原触发按钮。
- 真实数据均不足一页，上一页/下一页禁用状态正确。未把缺少真实第二页样本计为跨页验收成功。
- 注入 `state=UNKNOWN, policies=[]` 后，页面保留“待核实”，不会显示“没有策略”或停用按钮；撤销注入后真实策略查询恢复正常。
- 网络记录未出现 chat、审核、策略停用请求，浏览器无未捕获异常。

## 发现与处理

1. 概览返回 `totalShortLinksScanned=1`，独立档案端点返回 2 条。源码核对确认：概览读取最新 `GroupRiskProfile`，扫描数是该次聚合传入的 `profiles.size()`；列表则按 `link_id` 各取最新档案，可以组合不同窗口。两个调用均未限定同一个 `batchId`，因此不能作为同批快照直接对齐。建议后续概览 DTO 披露批次与窗口，再核对当前样本的具体批次；本轮保留实际结果，未修改业务数据或推算统一数量。
2. 风险原因码为空时，空容器仍占据行高。已改为不渲染空原因容器；没有人工审核记录时改用明确空态文字，避免展示 `{}`。
3. 初版截图辅助在页面已经滚动时固定 `clip.y=0`，导致顶层抽屉未进入截图。已修正本轮自有验收脚本：页面先滚动到顶部，抽屉使用实际视口截图；这属于验收工具修正。
