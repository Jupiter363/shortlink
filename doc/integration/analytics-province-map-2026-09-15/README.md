# 省份地图接入验收

日期：2026-09-15。关联 Issue #50。本次仅修改前端展示与资源，不修改后端统计、数据库或运行服务。

## 交付

- 地域与网络 → 省份：固定卡片内地图/排名切换，查看大图打开 1000px 原生弹窗，约 60% 地图与 40% 排行。
- 34 省级区域使用本地、按需加载的 SVG 路径。固定 Apache ECharts 4.9.0 上游版本，保留南海附图及所有原始环，提供可复现生成器与完整来源许可文件。
- 填色使用正整数分档，只有明确的零值显示零访问；缺失灰纹、未识别、名称未匹配、重复名称分别保留。
- 悬停、点击与键盘选择联动地图和排行；原始占比保持当前维度口径，不再归一化。

## 验证结果

- 前端 82 项测试通过，包括新增 9 项省名映射、未知/零值、冲突、原始占比及极端整数分档测试。
- lint、生产构建通过。按需地图资源约 259.6 KB，gzip 94.2 KB；来源许可文件随 dist 输出。无新增 npm 依赖。
- 地图生成器 `--check` 从固定 commit 下载输入并核验哈希，输出逐字节相同；34 唯一省码、177 环和 16,173 个顶点及 12 环南海附图校验通过。
- 内置浏览器使用现有数据：默认分组 13 次访问均为省份未知，地图保持缺失灰纹，13 次单独出现在未定位列表；UAT统计维度样本的广东 3 次、100.0% 与地图填色/排行/选中信息一致。
- 悬停排行高亮地图广东区域；点击固定选择。地图只有一个 Tab 入口，End 定位澳门、Enter 可选中；Escape 一次关闭弹窗并返回查看大图按钮。
- 320×740 下全屏弹窗地图上下排列，点击广东可读到 3 次/100.0%；页面宽度 320，弹窗 clientWidth 与 scrollWidth 均为 305，无横向溢出。

## 实测范围

真实样本仅有一个已识别省份；多地区分档、零值、未匹配和冲突使用纯数据测试验证，没有向开发环境植入模拟流量。底图是历史概览边界，不表示实时行政边界服务。本次没有修复数据采集中的省份未知问题，也没有重启后端或运行压测。
