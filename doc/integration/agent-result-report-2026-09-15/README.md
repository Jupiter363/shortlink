# 双 Agent 分析报告验收

关联 Issue #57，基于 main `7a4767f`。

## 修改范围

初始页面删除重复的数据核验模块，保留原分析方向卡片。分析开始后移除常驻提问卡，完整结果采用报告布局：问题、提交范围、返回时间和操作集中呈现；提示前置；正文安全渲染 Markdown；旁列显示真实证据目录、来源说明、执行概况及动作核验入口。继续分析、完整证据和执行轨迹使用弹窗/抽屉，不推挤正文。

报告沿用已保存的问题与范围快照，失败后的旧回答明确标注。详情切换仅重置抽屉滚动，不改变背景阅读位置。继续分析校验错误在弹窗内展示，聚焦时等待原生 dialog 打开。已执行状态仅代表后端命令 COMMITTED，界面明确为“命令已提交 · 传播待核实”。
