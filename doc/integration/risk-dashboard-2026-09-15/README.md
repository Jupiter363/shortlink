## 数据与操作边界

风险总数来自分组画像；头部档案最多 10 条、完整档案最多 500 条，未用于回算全组数量。人工关注不等于待处置，全组策略停用数未知时保持“—”。事件第一页预览独立于完整列表分页；事件和档案读取失败时不呈现虚假的零条总数。

此次浏览器验收未提交人工审核或策略停用，也未创建测试数据。当前可用分组已存在画像，NOT_EVALUATED、未知策略和命令传播语义由既有模型回归与只读代码复核覆盖；没有通过浏览器伪造后台响应。真实事件只有一页，跨页迟到响应保护通过代码复核。

测试输出中的 Node MODULE_TYPELESS_PACKAGE_JSON 提示为项目原有模块配置提示，不影响通过结果。本次未变更依赖或后端接口。
