# 访问统计仪表盘重设计 · 2026-09-15

关联 Issue #47。本轮先审查真实页面及统计合同，再重设计布局。沿用 Vue 3、现有 R 组件与明亮木星主题；taste-skill 采用现状审计、层级、间距和品牌一致性原则，仪表盘不套用其营销页模板。

## 问题分析

- 概览与维度分离，无法同时比较趋势、访问时段、访客和设备。
- 十个维度平铺为同一级选择，没有按分析问题归类。
- 小时数据被拆成 24 张卡片；原 390×844 下内容高 2879px，峰值需要下滚才能看到。
- 国家只有一条未知记录时仍占据整宽面板，信息量与卡片面积不匹配。
- 完整度提示与多个状态标签抢占首屏，筛选行内展开会推移图表。
- 原数量条使用最小 2% 宽度，使真实零值也出现色条；趋势缺少纵轴刻度。

## 最终布局

- 顶部导航只显示页面标题。当前范围、日期和访问记录／筛选／数据说明放在仪表盘自己的工具栏。
- 筛选使用 640px 弹窗；数据说明使用 560px 弹窗。打开和关闭均不改变仪表盘几何位置。取消筛选恢复已应用条件。
- 四张核心指标卡等宽、高约 108px，仅 PV 使用浅蓝强调色。
- 桌面使用三列网格：主趋势跨两列，访问时段占一列；第二排为访客构成、设备环境、地域与网络。分析卡统一 280px 高，内部长内容可滚动。
- 1100px 以下分析区两列；760px 以下单列，指标为两列。手机趋势 300px、时段 280px、分类卡 260px；三个工具栏按钮等宽排列。

| 模块 | 维度 | 展示方式 |
| --- | --- | --- |
| 访问趋势 | 每日 PV／UV／UIP | 带刻度折线图、可切换每日数据表 |
| 访问时段 | 24 小时、星期 | 时序柱状图，鼠标及键盘读取单桶数值 |
| 访客构成 | 新老访客、高频 IP | 人数及占比、脱敏 TopK 榜单及误差 |
| 设备环境 | 设备、操作系统、浏览器 | 对齐的数量排名与原始占比 |
| 地域与网络 | 国家、省份、运营商／ISP | 数量排名，未知项独立灰色展示 |

## 数据边界

不改接口、授权范围、日期校验和统计映射。缺失值不补零，分类占比不重新归一化；省份、新老访客保持各自分母。小时和星期仍是访问次数，新老访客仍按保留数据中的首次观测划分。TopK 是近似结果，保留脱敏标识、误差和非全量说明。历史覆盖和采集质量可查看；本轮不修复上游统计缺口。

## 验证

- 前端 73 项测试通过，lint、生产构建通过。
- 内置浏览器使用默认分组与 UAT 统计维度样本，逐一切换全部十个维度；小时 24 桶、星期 7 桶，零值柱高为零。
- 验证 PV／UV 切换、七天趋势表、筛选应用和取消、数据说明、访问记录抽屉与真实脱敏记录。
- 弹窗开关前后主趋势纵坐标一致；顶部页面标题容器业务按钮数量为零。
- 最终 1440×900 下内容高度与可视高度均为 776px；主趋势约 734×280px，维度卡约 361×280px。320×740 下页面宽度为 320px，无横向溢出，三个工具栏按钮均约 76px 宽且文本不溢出。390×844 和 1280×600 也检查可达性，长内容保留内部滚动。
- 独立代码复审指出键盘焦点与悬停读数冲突、大数纵轴宽度不足，均已修复。

生产构建挂载至正在运行的本地前端，未重启后端或中间件，未进行业务写入或压测。
