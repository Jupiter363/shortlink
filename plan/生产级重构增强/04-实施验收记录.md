## 实测发现并修复的问题

- 同物理分片移组先插后删会撞主键；改为同事务内读取旧行、删除再插入新归属。
- ShardingSphere 加密字段配置参数和运行时 H2 元数据依赖影响真实启动；按实际构造器及打包依赖修正。
- APISIX 节点映射键不展开环境变量导致 DNS 超时；改为节点数组的 host 值。
- Gateway 缺少 Boot repackage，无法直接运行制品；补齐可执行打包。
- SQL 权威注册仍被 Redisson/Bloom 的启动连接依赖阻断；去除无实际判定作用的 Bloom/Redisson 依赖。
- MySQL REPEATABLE READ 下策略快照可能拼接新 revision 与旧放行内容；在资源锁内使用一致的当前读取，并增加真实双事务交错测试。
- Command 已提交创建后的响应中，shortUri、批量 linkId 及派生 success 字段与 Admin 严格解码不一致；补全字段和只读派生契约，并验证其他未知字段仍拒绝。
- 已生效限流策略撤销或自然到期后，保留原窗口的剩余预算身份，防止换 windowSeconds 生成新 Redis 键绕过当前额度；迟到重算不延长到新的无关窗口。
- 号段的跨实例 ID 顺序不能代表创建时序；分页使用固定 created_at 和 linkId 排序，并有专用索引。
- 禁止抓取端口的合法创建意图曾可能留下 PENDING 元数据；改为持久记录意图，再由受限抓取流程写入匹配代次的 FAILED。
- 统计查询先按授权链接过滤会漏掉同事件跨链接的冲突副本；调整为先在租户及固定 cut 内隔离冲突，再过滤当前授权链接，真实 ClickHouse 验证单链接和多链接查询一致。
- 事件 ID 只去重、不约束时间，错误复用后可能跨窗口漏过冲突检查；点击与结果事件统一绑定首次 occurredAt，入口隔离时间不匹配的副本，避免引入逐事件全局数据库索引。
- 共享 APISIX etcd 配置不能代表一个节点身份；生产者身份包含部署名、hostname 和进程启动标识，并在请求上下文中固定上游与日志共用的 request-id。
- 忽略的本机 YAML 原本仍可能被 Maven 资源复制打包；父构建显式排除这些本地配置，生产配置占位符和环境覆盖改由受版本管理的 properties 验证。
